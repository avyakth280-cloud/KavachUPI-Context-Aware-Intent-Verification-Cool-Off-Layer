# KavachUPI-Context-Aware-Intent-Verification-Cool-Off-Layer
Pre-debit, context-aware intent verification &amp; cool-off layer for UPI. Detects live call coercion (VoIP/cellular) and screen sharing on-device to pause high-risk payments before UPI PIN entry (₹0 debited)—keeping everyday transfers instant (&lt;2s) while protecting victims with family co-signer approval and 1930 cybercrime logging.
